# Python 知识库网站 - 部署与运维手册

> 本文档描述的是早期 Laravel / 宝塔方案草稿。当前实现为 Vue 3 + Express（见根目录 `README.md`），请勿执行文中的 `composer` / `php artisan` 步骤。

## 一、快速部署指南

### 1.1 环境要求

| 软件 | 最低版本 | 推荐版本 |
|------|----------|----------|
| PHP | 8.2 | 8.2+ |
| MySQL | 5.7 | 8.0+ |
| Redis | 6.0 | 6.2+ |
| Node.js | 18 | 18+ |
| Composer | 2.5 | 2.6+ |

### 1.2 一键部署脚本

```bash
# 在项目根目录执行
bash deploy.sh install
```

### 1.3 手动部署步骤

```bash
# 1. 进入项目目录
cd /www/wwwroot/python-knowledge-base

# 2. 安装 PHP 依赖
composer install --no-dev --optimize-autoloader

# 3. 安装前端依赖
cd frontend
npm install --production
npm run build

# 4. 配置环境变量
cd ..
cp .env.example .env
php artisan key:generate

# 5. 配置数据库
# 编辑 .env 文件，设置数据库连接信息

# 6. 执行数据库迁移
php artisan migrate --force

# 7. 填充种子数据
php artisan db:seed

# 8. 设置权限
chmod -R 775 storage bootstrap/cache
```

## 二、配置说明

### 2.1 环境变量配置

| 变量 | 说明 | 示例 |
|------|------|------|
| APP_NAME | 应用名称 | Python 知识库 |
| APP_ENV | 环境 | production |
| APP_KEY | 应用密钥 | base64:xxx |
| APP_URL | 应用地址 | https://your-domain.com |
| DB_CONNECTION | 数据库类型 | mysql |
| DB_HOST | 数据库主机 | 127.0.0.1 |
| DB_PORT | 数据库端口 | 3306 |
| DB_DATABASE | 数据库名 | python_knowledge |
| DB_USERNAME | 数据库用户名 | your_username |
| DB_PASSWORD | 数据库密码 | your_password |
| REDIS_HOST | Redis 主机 | 127.0.0.1 |
| REDIS_PORT | Redis 端口 | 6379 |
| MAIL_MAILER | 邮件驱动 | smtp |
| GITHUB_CLIENT_ID | GitHub Client ID | your_client_id |
| GITHUB_CLIENT_SECRET | GitHub Client Secret | your_client_secret |

### 2.2 宝塔面板配置

#### 网站配置

- 网站根目录: `/www/wwwroot/python-knowledge-base/public`
- PHP 版本: 8.2
- 伪静态: 见 deploy.sh 中的 Nginx 配置

#### 定时任务

```
类型: Shell 脚本
周期: 每分钟
命令: cd /www/wwwroot/python-knowledge-base && php artisan schedule:run >> /dev/null 2>&1
```

#### 守护进程

```
名称: queue-worker
命令: php /www/wwwroot/python-knowledge-base/artisan queue:work --sleep=3 --tries=3
```

## 四、故障排查

### 4.1 常见问题

#### 问题 1: 500 内部服务器错误

**原因**: 权限问题或配置错误

**解决**:
```bash
chmod -R 775 storage bootstrap/cache
php artisan config:clear
```

#### 问题 2: 数据库连接失败

**原因**: .env 配置错误

**解决**:
```bash
# 检查数据库连接
php artisan db:test

# 检查 .env 配置
cat .env | grep DB_
```

#### 问题 3: 队列不工作

**原因**: 守护进程未启动

**解决**:
```bash
# 检查队列状态
php artisan queue:work --status

# 重启队列
php artisan queue:restart
```

#### 问题 4: GitHub 登录失败

**原因**: OAuth 配置错误

**解决**:
1. 检查 GitHub OAuth 应用配置
2. 检查 GITHUB_CLIENT_ID 和 GITHUB_CLIENT_SECRET
3. 检查回调 URL 是否正确
