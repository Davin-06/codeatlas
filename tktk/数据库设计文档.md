# Python 知识库网站 - 数据库设计文档

> 本文档描述的是早期 Laravel / MySQL 方案草稿。当前实现使用 JSON 文件存储（`server/data/`），不再依赖 MySQL 或 `database/migrations`。

## 一、数据库概述

**数据库类型**: MySQL 5.7+  
**字符集**: utf8mb4  
**排序规则**: utf8mb4_unicode_ci  
**迁移文件**: `database/migrations/2024_01_01_000001_create_python_knowledge_tables.php`

## 二、表结构

### 2.1 用户表 (users)

```sql
CREATE TABLE `users` (
  `id` char(36) NOT NULL,
  `email` varchar(255) NOT NULL,
  `password` varchar(255) NOT NULL,
  `nickname` varchar(20) DEFAULT NULL,
  `name` varchar(50) DEFAULT NULL,
  `avatar` varchar(500) DEFAULT NULL,
  `bio` text DEFAULT NULL,
  `github_id` varchar(255) DEFAULT NULL,
  `github_username` varchar(255) DEFAULT NULL,
  `email_verified_at` datetime DEFAULT NULL,
  `status` enum('active','disabled','deleted') NOT NULL DEFAULT 'active',
  `created_at` datetime NOT NULL,
  `updated_at` datetime NOT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `users_email_unique` (`email`),
  UNIQUE KEY `users_github_id_unique` (`github_id`),
  KEY `users_status_index` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| email | VARCHAR(255) | 邮箱（唯一） |
| password | VARCHAR(255) | bcrypt 加密密码 |
| nickname | VARCHAR(20) | 昵称 |
| name | VARCHAR(50) | 姓名 |
| avatar | VARCHAR(500) | 头像 URL |
| bio | text | 个人简介 |
| github_id | VARCHAR(255) | GitHub ID |
| github_username | VARCHAR(255) | GitHub 用户名 |
| email_verified_at | datetime | 邮箱验证时间 |
| status | ENUM | 账号状态 |
| created_at | datetime | 创建时间 |
| updated_at | datetime | 更新时间 |

### 2.4 系统知识表 (knowledge)

```sql
CREATE TABLE `knowledge` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `title` varchar(255) NOT NULL,
  `content` text NOT NULL,
  `version` varchar(10) NOT NULL,
  `category` varchar(50) NOT NULL,
  `tags` json DEFAULT NULL,
  `author` varchar(255) DEFAULT NULL,
  `source` varchar(255) DEFAULT NULL,
  `is_system` tinyint(1) NOT NULL DEFAULT '1',
  `order` int NOT NULL DEFAULT '0',
  `status` enum('draft','published','archived') NOT NULL DEFAULT 'published',
  `created_at` datetime NOT NULL,
  `updated_at` datetime NOT NULL,
  PRIMARY KEY (`id`),
  KEY `knowledge_version_index` (`version`),
  KEY `knowledge_category_index` (`category`),
  KEY `knowledge_is_system_index` (`is_system`),
  KEY `knowledge_status_index` (`status`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | BIGINT | 主键 |
| title | VARCHAR(255) | 标题 |
| content | text | 内容 |
| version | VARCHAR(10) | Python 版本 |
| category | VARCHAR(50) | 分类 |
| tags | JSON | 标签 |
| author | VARCHAR(255) | 作者 |
| source | VARCHAR(255) | 来源 |
| is_system | BOOLEAN | 是否系统知识 |
| order | INT | 排序 |
| status | ENUM | 状态 |

### 2.5 知识库表 (knowledge_bases)

```sql
CREATE TABLE `knowledge_bases` (
  `id` char(36) NOT NULL,
  `user_id` char(36) NOT NULL,
  `name` varchar(50) NOT NULL,
  `description` text DEFAULT NULL,
  `tags` json DEFAULT NULL,
  `is_shared` tinyint(1) NOT NULL DEFAULT '0',
  `share_permission` enum('view_only','allow_comment','allow_favorite') NOT NULL DEFAULT 'view_only',
  `share_id` char(32) DEFAULT NULL,
  `share_expires_at` datetime DEFAULT NULL,
  `view_count` int NOT NULL DEFAULT '0',
  `favorite_count` int NOT NULL DEFAULT '0',
  `status` enum('draft','published','archived','deleted') NOT NULL DEFAULT 'draft',
  `created_at` datetime NOT NULL,
  `updated_at` datetime NOT NULL,
  PRIMARY KEY (`id`),
  KEY `knowledge_bases_user_id_foreign` (`user_id`),
  UNIQUE KEY `knowledge_bases_share_id_unique` (`share_id`),
  KEY `knowledge_bases_is_shared_index` (`is_shared`),
  KEY `knowledge_bases_status_index` (`status`),
  CONSTRAINT `knowledge_bases_user_id_foreign` FOREIGN KEY (`user_id`) REFERENCES `users` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4;
```

**字段说明**:

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 所属用户 |
| name | VARCHAR(50) | 知识库名称 |
| description | text | 描述 |
| tags | JSON | 标签 |
| is_shared | BOOLEAN | 是否分享 |
| share_permission | ENUM | 分享权限 |
| share_id | CHAR(32) | 分享 ID |
| share_expires_at | datetime | 分享有效期 |
| view_count | INT | 访问次数 |
| favorite_count | INT | 收藏次数 |
| status | ENUM | 状态 |

## 四、索引优化

### 4.1 查询优化建议

```sql
-- 知识查询
SELECT * FROM knowledge 
WHERE version = '3.8' AND category = '常用库' 
ORDER BY created_at DESC;

-- 知识库查询
SELECT * FROM knowledge_bases 
WHERE user_id = 'uuid' AND status = 'published';

-- 分享查询
SELECT * FROM share_records 
WHERE share_id = 'abc123';
```

### 4.2 索引策略

| 表 | 索引类型 | 说明 |
|------|----------|------|
| users | 唯一索引 | email, github_id |
| knowledge | 普通索引 | version, category, is_system |
| knowledge_bases | 唯一索引 | share_id |
| favorites | 联合唯一索引 | user_id + knowledge_id |

## 五、数据迁移

### 5.1 执行迁移

```bash
# 执行所有迁移
php artisan migrate

# 回滚最后一次迁移
php artisan migrate:rollback

# 回滚所有迁移并重新执行
php artisan migrate:fresh

# 刷新迁移并填充数据
php artisan migrate:refresh --seed
```

### 5.2 种子数据

```bash
# 执行所有种子
php artisan db:seed

# 指定种子类
php artisan db:seed --class=KnowledgeSeeder
```
