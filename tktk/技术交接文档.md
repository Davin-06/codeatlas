## 二、技术栈详解

### 2.1 后端技术栈

| 技术 | 版本 | 用途 | 安装命令 |
|------|------|------|----------|

| 技术 | 版本 | 用途 | 安装命令 |
|------|------|------|----------|

## 三、数据库设计

### 3.1 核心表结构

#### users (用户表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| email | VARCHAR(255) | 邮箱（唯一） |

| 字段 | 类型 | 说明 |

| category | VARCHAR(50) | 分类 |
| tags | JSON | 标签 |
| is_system | BOOLEAN | 是否系统知识 |

#### knowledge_bases (用户知识库表)

| 字段 | 类型 | 说明 |
|------|------|------|
| id | UUID | 主键 |
| user_id | UUID | 所属用户 |
| name | VARCHAR(50) | 知识库名称 |
| is_shared | BOOLEAN | 是否分享 |

## 五、部署指南

### 5.1 宝塔面板部署步骤

#### 步骤 1: 安装必要软件

在宝塔面板软件商店安装：
- PHP 8.2
- MySQL 5.7+
- Redis 6.2+
- Nginx 1.20+

#### 步骤 2: 创建网站

1. 在宝塔面板添加网站
2. 域名: your-domain.com
3. 根目录: /www/wwwroot/python-knowledge-base/public
4. PHP 版本: 8.2

#### 步骤 3: 配置伪静态

```nginx
location / {
    try_files $uri $uri/ /index.php?$query_string;
}

location ~ \.php$ {
    fastcgi_pass  unix:/tmp/php-cgi-82.sock;
    fastcgi_index index.php;
    fastcgi_param SCRIPT_FILENAME $document_root$fastcgi_script_name;
    include fastcgi_params;
}
```

#### 步骤 4: 配置环境变量

编辑 `.env` 文件：

```env
APP_NAME="Python 知识库"
APP_ENV=production
APP_KEY=base64:YOUR_APP_KEY_HERE
APP_URL=https://your-domain.com

DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=python_knowledge
DB_USERNAME=your_username
DB_PASSWORD=your_password

REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

MAIL_MAILER=smtp
MAIL_HOST=smtp.example.com
MAIL_PORT=587
MAIL_USERNAME=your_email@example.com
MAIL_PASSWORD=your_email_password
```

#### 步骤 5: 执行部署脚本

```bash
cd /www/wwwroot/python-knowledge-base

# 安装 PHP 依赖
composer install --no-dev --optimize-autoloader

# 安装前端依赖
cd frontend
npm install --production
npm run build

# 生成应用密钥
cd ..
php artisan key:generate

# 执行数据库迁移
php artisan migrate --force

# 填充种子数据
php artisan db:seed

# 设置权限
chmod -R 775 storage bootstrap/cache
```

#### 步骤 6: 配置定时任务

在宝塔面板添加定时任务：

```
类型: Shell 脚本
任务周期: 每分钟
脚本内容: cd /www/wwwroot/python-knowledge-base && php artisan schedule:run >> /dev/null 2>&1
```

#### 步骤 7: 配置队列（可选）

在宝塔面板添加守护进程：

```
进程类型: 守护进程
启动命令: php /www/wwwroot/python-knowledge-base/artisan queue:work --sleep=3 --tries=3
```

### 5.2 SSL 配置

1. 在宝塔面板选择网站
2. 点击 SSL
3. 申请 Let's Encrypt 证书
4. 开启强制 HTTPS

### 5.3 监控配置

建议配置以下监控项：
- 网站访问量监控
- CPU/内存使用率监控
- 磁盘空间监控
- 数据库连接数监控

## 六、运维手册

### 6.1 日常运维命令

```bash
# 查看日志
tail -f storage/logs/laravel.log

# 清理缓存
php artisan cache:clear
php artisan config:clear
php artisan route:clear
php artisan view:clear

# 查看队列状态
php artisan queue:work --status

# 备份数据库
php artisan db:backup

# 查看系统状态
php artisan stats:show
```

### 6.2 故障排查

| 问题 | 可能原因 | 解决方案 |
|------|----------|----------|
| 500 错误 | 权限问题 | `chmod -R 775 storage bootstrap/cache` |
| 数据库连接失败 | .env 配置错误 | 检查 DB_* 配置项 |
| 队列不工作 | 守护进程未启动 | 检查队列守护进程状态 |
| 邮件发送失败 | 邮件配置错误 | 检查 MAIL_* 配置项 |
| GitHub 登录失败 | OAuth 配置错误 | 检查 GITHUB_* 配置项 |

### 6.3 性能优化

```bash
# 优化 Composer
composer install --optimize-autoloader --no-dev

# 缓存配置
php artisan config:cache
php artisan route:cache
php artisan view:cache

# 优化数据库
php artisan optimize:clear
```
